# Security Policy

## Reporting a Vulnerability

Please do not open a public GitHub issue for suspected security vulnerabilities.

Use GitHub's private vulnerability reporting feature instead:

1. Open the repository's **Security** tab.
2. Select **Advisories**.
3. Select **Report a vulnerability**.

Include as much of the following information as possible:

- A clear description of the vulnerability
- The affected page, route, or component
- Steps required to reproduce the issue
- The potential impact
- Any suggested fix or mitigation

Please avoid accessing, modifying, downloading, or sharing customer information while investigating an issue.

## Response Process

Reports will be reviewed as soon as reasonably possible. You can generally expect:

- Acknowledgement within 7 days
- An initial assessment after the report has been reviewed
- Updates when meaningful progress has been made

Please allow time for a fix to be developed and deployed before publicly discussing the vulnerability.

## Supported Version

Security updates are applied to the version currently deployed at [360-epoxy.com](https://360-epoxy.com). Older commits and previous deployments are not supported.

## Scope

Good-faith security research is welcome when it avoids:

- Accessing or exposing customer information
- Submitting excessive contact-form requests
- Denial-of-service testing
- Social engineering or phishing
- Testing third-party services without their permission
- Disrupting the live website or business operations

Thank you for helping keep the website and its visitors safe.
